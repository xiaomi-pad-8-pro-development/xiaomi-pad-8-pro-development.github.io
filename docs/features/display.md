# Display modes

The screen is an LCD panel with 3200 × 2136 pixels. It can run at 60, 90,
120 and 144 Hz.

## Refresh rate

By default apps can run at up to **144 Hz**. To save battery, pick a lower
peak rate:

1. Open **Settings → Display**.
2. Find the refresh rate option and pick a lower value.

## Xiaomi display modes

These come with [Xiaomi Parts](xiaomi-parts.md), in **Settings → Xiaomi
features → Display**.

| Mode | What it does |
| --- | --- |
| **Reading mode** | Warmer, paper-like colours that are easier on the eyes |
| **Sunlight mode** | Makes the screen easier to read in bright light |
| **True Tone** | Changes the white balance to match the light around you |
| **Colour** | Choose the colour style of the screen |

!!! note
    Reading mode needs Xiaomi's display driver. It works on the 6.6
    kernel. On the 6.12 test kernel it does not work yet. See
    [Kernels](../kernels.md).
