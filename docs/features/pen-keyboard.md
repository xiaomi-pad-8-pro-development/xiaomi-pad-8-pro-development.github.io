# Pen and keyboard

## Xiaomi Focus Pen

1. Open **Settings → Xiaomi features → Stylus**.
2. Follow the pairing steps on screen. The pen connects over Bluetooth.
3. From the same page you can:
    - see the pen battery,
    - set up the pen buttons,
    - use the laser pointer,
    - update the pen firmware.

Pen pressure works in Xiaomi Notes and other drawing apps.

!!! tip "Quick note"
    Touch the pen on the dark (off) screen to wake it and open a quick
    note.

## Keyboard cover

2. Open **Settings → Xiaomi features → Keyboard** to set shortcuts, use
