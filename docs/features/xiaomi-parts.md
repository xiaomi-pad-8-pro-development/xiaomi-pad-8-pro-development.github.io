# Xiaomi Parts

Xiaomi Parts brings back the Xiaomi hardware features that stock Android
does not have. You find them in **Settings → Xiaomi features**.

!!! note "Coming soon"
    The exact Settings entry name on each ROM.

| Part | What it does |
| --- | --- |
| **Stylus** | Focus Pen pairing, battery, pressure, buttons, laser pointer and firmware |
| **Keyboard** | Keyboard cover shortcuts, firmware and touchpad |
| **Bypass charging** | A Quick Settings tile that runs the tablet from the charger without charging the battery |
| **Display** | Reading mode, sunlight mode, True Tone and colour |
| **Pencil engine** | The pen engine Xiaomi Notes uses for handwriting |

See [Pen and keyboard](pen-keyboard.md) and [Display modes](display.md)
for how to use them.

## Bypass charging

Use it for long gaming or video sessions on the charger. It keeps the
battery cooler.

1. Pull down Quick Settings and edit the tiles.
2. Add the **Bypass charging** tile.
3. Tap it while the charger is connected.
