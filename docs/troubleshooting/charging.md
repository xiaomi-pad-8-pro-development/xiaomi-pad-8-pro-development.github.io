# Charging

## Slow charging with another brand's charger

With a non-Xiaomi USB PD (PPS) charger, the tablet charges at about
**18 W**. This is normal. The charging chip only allows fast charging
after a handshake with a Xiaomi charger. A software change cannot unlock
this.

For fast charging, use the **official Xiaomi charger**.

## Slow charging when the battery is almost empty

Below a few percent, the battery charges slowly on purpose to protect it
(pre-charge). This is normal. Check the speed again above 20%.

## Charging in recovery

The recovery charges slowly, at 5 V. That is enough to keep the battery
from running out while you work.

!!! tip "Is it really charging?"
    The status can say "Charging" even when the battery is slowly
    draining. Watch the battery **percentage** for a few minutes. If it
    goes up, it is charging.

## Bypass charging

To run the tablet from the charger without charging the battery, see
[Xiaomi Parts](../features/xiaomi-parts.md#bypass-charging).
