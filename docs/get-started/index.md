# What this is

This project makes community Android software for the Xiaomi Pad 8 Pro
(code name **piano**).

## What you get

- **Android 17 ROMs.** LineageOS-based builds and Evolution X. They use
  the HyperOS 4 China firmware `OS4.0.6.0.XPYCNXM`, and the firmware is
  included in the ROM.
- **A custom kernel** called **alxp**. There is also a root build with
  KernelSU-Next. See [Kernels](../kernels.md).
- **Recoveries.** TWRP 16, YARP and OrangeFox. They can unlock your
  encrypted data, install zips and make backups.
- **Optional extras.** Settings for the Focus Pen, keyboard cover and
  display, the Xiaomi camera, Xiaomi Notes, and an offline notes app.
  Which extras are in a build depends on that build.
