# Repositories

All code is in the GitHub organisation
[xiaomi-pad-8-pro-development](https://github.com/xiaomi-pad-8-pro-development).

| Repository | Branch | Purpose |
| --- | --- | --- |
| `android_device_xiaomi_piano` | `seventeen` | Device tree: how Android is built for piano |
| `android_device_xiaomi_piano-kernel` | `6.6`, `6.6-ksu` | Ready-made kernel files used by the ROM |
| `android_kernel_xiaomi_piano` | `6.6`, `6.12`, `6.12-source` | Kernel source (alxp) |
| `auto` | `main` | Script that builds the kernel into the prebuilts |
| `android_vendor_xiaomi_piano` | `seventeen` | Stock HyperOS files (blobs and firmware) |
| `android_device_xiaomi_piano-xiaomi-parts` | `seventeen` | Optional: Focus Pen, keyboard, bypass charging, display settings |
| `android_device_xiaomi_piano-alxp-parts` | `seventeen` | Optional: AirPods switching, iPhone notifications, Mac clipboard and second screen |
| `android_device_xiaomi_piano-patches` | `seventeen` | Optional: patches to the ROM source |
| `android_vendor_xiaomi_piano-xiaomi-camera` | `seventeen` | Optional: stock Xiaomi camera app |
| `android_vendor_xiaomi_piano-xiaomi-notes` | `seventeen` | Optional: Xiaomi Notes without a Xiaomi account |
| `android_device_xiaomi_piano-aosp-notes` | `seventeen` | Optional: offline notes app with pen ink |
| `android_hardware_qcom_thermal` | `seventeen` | Thermal HAL with a fallback skin sensor |
| `android_device_xiaomi_piano-recovery` | `seventeen` | TWRP, YARP and OrangeFox |
| `local_manifests` | `seventeen` | Lists the trees to download for a build |
| `android_device_xiaomi_piano-uefi` | `main` | UEFI firmware (experimental) |
| `android_device_xiaomi_piano-unixnu` | `main` | iPadOS port (experimental) |
| `android_device_xiaomi_piano-kernel-mainline` | `7.2` | Mainline Linux (experimental) |
